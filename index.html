Como o Tessera decide

Primeiro a prova, depois o consenso

Os quatro agentes começam juntos, cada um com seu prazo. O Tessera decide na ordem abaixo e cancela quem ficou para trás.

1Verificação

A resposta que passa nos testes

Com --verify, cada resposta é testada assim que chega. A primeira que passa encerra o fanout e volta como está, sem ninguém reescrever.

2Maioria

Duas respostas iguais vencem

Sem testes, o Tessera compara as respostas. Quando duas coincidem, essa volta direto, sem esperar os outros agentes.

3Síntese

Só no impasse

Se ninguém passou e ninguém concorda, um agente junta as respostas. Se a síntese falhar, volta uma resposta pronta em vez de nada.

Comandos

Funciona com os agentes que você já usa

Node puro, sem dependências. Os quatro agentes podem rodar por um provedor só, sem login em cada um.

$ git clone https://github.com/dheiver2/tessera.git && cd tessera
$ npm test            # Node 20+, sem dependências
$ npm link            # deixa o comando tessera no PATH
$ tessera doctor      # confere os agentes instalados

tessera sync

Uma configuração só (regras, skills, MCP) escrita no formato de cada agente, sem apagar o que é seu.

tessera fanout

A mesma tarefa para os quatro, com verificação, maioria e síntese só no impasse.

tessera pipeline

Encadeia agentes: um planeja, outro implementa, outro revisa.

tessera do · delegate

Manda a tarefa para um agente só, em primeiro plano ou em segundo.

tessera eval

Mede cada agente sozinho e o Tessera nas mesmas tarefas, com testes privados.

tessera doctor

Mostra o que está instalado, o que está sincronizado e o que falta.
