Ask four agents.
Keep the answer that works.

Tessera is a harness for coding agents. It runs Claude Code, Codex, OpenClaw and Hermes on the same task and keeps the answer that passes the tests; with no tests, the one most of them agree on. Open source, MIT license.

How Tessera decides

Proof first, then consensus

The four agents start together, each with its own deadline. Tessera decides in the order below and cancels whoever is left behind.

1Verification

The answer that passes the tests

With --verify, each answer is tested as soon as it arrives. The first one that passes ends the fanout and comes back untouched, with no rewriting.

2Majority

Two matching answers win

With no tests, Tessera compares the answers. When two match, that one comes back right away, without waiting for the other agents.

3Synthesis

Only on deadlock

If nobody passed and nobody agrees, one agent merges the answers. If the synthesis fails, a finished answer comes back instead of nothing.

Commands

Works with the agents you already use

Plain Node, no dependencies, no install. Any two or more agents; each uses its own login, or all go through any gateway you choose.

$ npx github:dheiver2/tessera doctor     # finds your agents, Node 22+
$ npx github:dheiver2/tessera fanout "your question"

tessera sync

One configuration (rules, skills, MCP) written in each agent's format, without touching what is yours.

tessera fanout

The same task to all four, with verification, majority, and synthesis only on deadlock.

tessera pipeline

Chain agents: one plans, another implements, another reviews.

tessera do · delegate

Send a task to a single agent, in the foreground or in the background.

tessera eval

Measure each agent alone and Tessera on the same tasks, with private tests.

tessera doctor

Shows what is installed, what is in sync and what is missing.

Latency: p95 from 251–271 s to 150 s (Nov 6–7, 2026, 4 rounds)

The fast agent gets 20 s alone (--hedge); after that, the others start and it keeps running as one more branch. When there is nothing to check, as in questions and reviews, everyone starts at once. Each task has a 150 s budget (--budget), and the micro-agent asks for test cases three times, keeping only the ones two samples agree on. About the same accuracy as before (26.75 vs. 27.5 of 33). The 2.27× is round 5, where OpenClaw tied for best with a 66 s p95; against Claude, the other tied agent, it is 1.25×.
