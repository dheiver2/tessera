# Revisão de código

1. Leia o diff completo antes de comentar.
2. Verifique: erros de lógica, entradas não validadas, segredos no código, testes ausentes.
3. Reporte achados por severidade (bloqueante, importante, sugestão) com `arquivo:linha`.
4. Não reescreva o código sem pedido; sugira.
